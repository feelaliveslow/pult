# Пульт — управление ноутбуком с iPhone

Видите экран ноутбука на iPhone и управляете им пальцами: клики, перетаскивание,
прокрутка, клавиатура (в том числе по-русски), сочетания клавиш.

- **Без App Store и без Mac.** Приложение открывается в Safari и добавляется
  на экран «Домой» — дальше запускается как обычное приложение, во весь экран.
- **Быстро.** Видео идёт через WebRTC в H.264: iPhone декодирует его аппаратно,
  задержка в локальной сети — десятки миллисекунд. Команды мыши и клавиатуры
  идут отдельным каналом и не ждут видео.
- **Работает на любом расстоянии.** В одной Wi‑Fi сети — сразу. Из кофейни, с работы
  или по мобильному интернету — через бесплатный Tailscale (см. ниже), без настройки роутера.
- **Ноутбук:** Windows 10/11, macOS, Linux (X11).

## 1. Установка на ноутбук

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/);
на Windows при установке отметьте «Add Python to PATH»).

Скачайте этот репозиторий и запустите:

| Система | Что запустить |
|---|---|
| Windows | двойной щелчок по `start-windows.bat` |
| macOS | двойной щелчок по `start-mac.command` (если не открывается: правый щелчок → «Открыть») |
| Linux | `./start-linux.sh` |

Первый запуск сам установит зависимости. В окне появятся адрес, **код доступа** и QR‑код.

**Только для macOS:** при первом запуске разрешите приложению «Терминал»
(или тому, из которого запускаете) доступ в *Системные настройки → Конфиденциальность и безопасность*:

- **Запись экрана** — иначе будет чёрный экран;
- **Универсальный доступ** — иначе клики и клавиатура не будут работать;
- на вопрос «Разрешить входящие подключения?» ответьте «Разрешить».

После выдачи разрешений перезапустите программу.

## 2. Установка на iPhone

1. Наведите камеру iPhone на QR‑код в окне программы (или откройте в Safari адрес из окна).
2. В Safari: кнопка «Поделиться» → **«На экран „Домой“»**.
3. Открывайте «Пульт» с экрана «Домой» — во весь экран, без адресной строки.

Код доступа уже встроен в ссылку. Если программа попросит код, введите тот, что показан на ноутбуке.

## 3. Доступ из любого места (кофейня, мобильный интернет)

Используйте [Tailscale](https://tailscale.com) — бесплатную частную сеть между вашими устройствами.
Она работает через любой Wi‑Fi и 4G/5G, без проброса портов, и шифрует трафик.

1. Установите Tailscale на ноутбук и на iPhone (App Store), войдите в один аккаунт на обоих.
2. Перезапустите «Пульт» на ноутбуке. Первой строкой появится адрес `http://100.x.x.x:8765/…`
   с пометкой **Tailscale**, и QR‑код будет вести на него.
3. Откройте этот адрес на iPhone и добавьте на экран «Домой». Эта иконка работает и дома, и вне дома.

Расстояние не ограничено. Скорость зависит от **исходящей** скорости интернета там, где стоит ноутбук.
Для режима «Баланс» хватает 3 Мбит/с, для «Эконом» — 1 Мбит/с.

Чтобы ноутбук был доступен, когда вас нет рядом:
- программа «Пульт» должна быть запущена (пока она работает, ноутбук не засыпает);
- **крышку не закрывайте**: при закрытой крышке ноутбук уснёт. Можно убавить яркость до минимума;
- подключите зарядку.

## 4. Управление

Внизу — панель: **⌨︎** клавиатура · **Касание/Тачпад** режим · **Клавиши** · **⤢** вписать экран · **⚙︎** настройки · **▾** скрыть панель.

| Жест | Режим «Касание» | Режим «Тачпад» |
|---|---|---|
| Тап | клик в точку под пальцем | клик там, где курсор |
| Два тапа | двойной клик | двойной клик |
| Удержание ~0,5 с | правый клик | правый клик |
| Удержание, затем вести | перетаскивание (выделение, окна, файлы) | перетаскивание |
| Вести одним пальцем | прокрутка; при увеличении — сдвиг экрана | движение курсора |
| Два пальца — вести | прокрутка (с инерцией) | прокрутка |
| Тап двумя пальцами | правый клик | правый клик |
| Щипок | увеличение (до 6×) | увеличение (экран следует за курсором) |
| Тап тремя пальцами | клавиатура | клавиатура |

**Совет:** чтобы попасть по мелкой кнопке, увеличьте щипком и тапните. Для точной работы
с текстом переключитесь в «Тачпад».

**Клавиши:** Ctrl / Alt / Shift / Win (на Mac — Cmd / Option) работают как залипающие:
нажмите Ctrl, затем букву на клавиатуре iPhone или клик — получится Ctrl+буква или Ctrl+клик.
Есть стрелки, Esc, Tab, F1–F12, громкость, а также готовые сочетания: копировать, вставить,
отменить, сменить окно, диспетчер задач и т.д. Набор сочетаний подстраивается под систему ноутбука.
Сочетания срабатывают при любой раскладке ноутбука, в том числе при русской.

**Качество (⚙︎):**
- «Эконом» — 960 px, 20 fps, для слабой сети;
- «Баланс» — 1280 px, 30 fps;
- «Чётко» — 1920 px, мелкий текст;
- «60 fps» — плавно.

Там же: выбор монитора, скорость курсора и прокрутки, индикатор задержки.

## Параметры запуска

```bash
python laptop/server.py --port 8765        # другой порт
python laptop/server.py --monitor 1        # второй монитор
python laptop/server.py --new-token        # новый код доступа (старые ссылки перестанут работать)
python laptop/server.py --no-keep-awake    # разрешить ноутбуку засыпать
```

Код доступа хранится в `~/.screen-viewer/config.json`.

## Безопасность

- Без кода доступа подключиться нельзя. После 5 неверных попыток адрес блокируется на минуту.
- Видео и команды шифруются (WebRTC DTLS/SRTP). Через Tailscale шифруется и весь остальной трафик.
- Не открывайте порт 8765 в интернет через роутер — для удалённого доступа используйте Tailscale.
- Код доступа даёт полный контроль над ноутбуком. Если он мог утечь, запустите программу с `--new-token`.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| iPhone не открывает адрес | Телефон и ноутбук в одной сети? Или Tailscale включён на обоих? Брандмауэр Windows: разрешите Python доступ к частным сетям. |
| Чёрный экран на Mac | Разрешение «Запись экрана» (см. п.1), затем перезапуск. |
| Клики не работают на Mac | Разрешение «Универсальный доступ». |
| Клики не работают в отдельных окнах на Windows | Окна от имени администратора (диспетчер задач, установщики) не принимают ввод от обычной программы. Запустите `start-windows.bat` от имени администратора. |
| Экран блокировки Windows не управляется | Windows не позволяет обычным программам управлять экраном входа и окнами UAC. |
| Картинка дёргается или отстаёт | ⚙︎ → «Эконом». Включите индикатор задержки, чтобы видеть fps и пинг. |

## Как это устроено

```
iPhone (Safari / PWA)                                  Ноутбук (Python)
┌────────────────────────┐   HTTP POST /offer    ┌──────────────────────────────┐
│ web/app.js             │ ────────────────────▶ │ laptop/server.py (aiohttp)    │
│  жесты → команды       │   WebRTC data channel │  pynput → мышь/клавиатура     │
│  <video> ◀─────────────│ ◀──── H.264 видео ─── │  mss → кадр → libx264         │
└────────────────────────┘                       └──────────────────────────────┘
```
